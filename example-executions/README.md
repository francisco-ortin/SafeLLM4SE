# Example Executions

This directory contains example shell scripts that show how to run the SafeLLM4SE sampling and reporting commands with different evaluators.

Each execution is available in two formats:

- `.ps1` for Windows PowerShell.
- `.sh` for Linux, macOS, and WSL shells.

Run scripts from any directory; each script resolves the project root before invoking the corresponding Python wrapper.

Examples:

```powershell
.\example_executions\sampling\sample_random_normal_mean_60_sd_15.ps1
```

```bash
./example-executions/sampling/sample_random_normal_mean_60_sd_15.sh
```
